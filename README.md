# 克劳德安全环境搭建

> 面向 AI 的 Claude 网页端与 CLI 安全配置指南。项目目标是把检查、配置、登录和验收拆成可解释、可回退的步骤。
>
> **实测状态：待验证。** 当前仓库发布的是方案和提示词，尚未在目标设备完成端到端实测。只有完成下方验收清单并记录设备、日期和结果后，才能标记为“实测有效”。

## 项目文件

- [部署方案](deployment-plan.yaml)：机器可读的阶段、检查项、通过标准和失败处理。
- 本页“交给 AI 的提示词”：可直接复制到你选择的 AI 助手，让它先检查环境，再逐步协助你操作。

## 使用方法

1. 先阅读部署方案，确认目标是你本人控制的设备和账号。
2. 复制下面的提示词发送给 AI。若 AI 无法读取本仓库，把 deployment-plan.yaml 一并提供。
3. 按步骤查看它提出的检查和变更；涉及安装、配置修改、登录授权或付款时，逐项由你确认或亲自完成。
4. 完成网页端与 CLI 的实际请求后，按验收清单记录结果。不要把密码、验证码、访问令牌或支付卡信息发给 AI。

## 交给 AI 的提示词（复制代码块内容）

```text
你是我的 Claude 安全环境搭建助手。请用中文协助我在我本人控制的设备上准备 Claude 网页端和 Claude CLI，并逐步验证结果。

工作规则：
1. 先检查操作系统、Shell、浏览器、相关 CLI 是否已安装及其版本；先给出检查结果和计划，再执行任何会改变系统状态的操作。
2. 以本仓库 deployment-plan.yaml 为流程依据。若无法读取该文件，先让我提供文件；不要猜测其中不存在的步骤。
3. CLI 名称、安装命令、系统要求、账号授权方式都先核对 Anthropic 官方文档。只使用官方文档或官方发行渠道；不要从陌生脚本、网盘或非官方镜像安装软件。
4. 一次只推进一个阶段。每一步说明目的、命令会检查或改变什么、预期结果、失败时如何回退；执行后读取实际输出再继续。默认先做只读检查。
5. 运行任何安装、修改代理/DNS/系统设置、写入配置、清理文件或授权操作前，先说明具体影响并等我明确同意。不要为了方便关闭安全防护、证书校验或系统隔离。
6. 登录、邮箱验证、CAPTCHA、KYC、订阅条款和付款由我本人在官方界面完成。不要索要、读取或代填我的密码、验证码、会话令牌、API 密钥、支付卡资料或真实账单信息；不要绕过地区限制、身份验证或反滥用检查。
7. 使用本人长期可访问的邮箱。不要建议公开临时邮箱或共享收件箱作为账号邮箱。不要在日志或普通文档中保存秘密。
8. 不要重复提交支付。若支付结果不明或已扣款但订阅未生效，先让我核对订单并联系官方支持。
9. 分别验收浏览器登录、网页端普通请求、CLI 授权、CLI 普通请求；一个成功不代表其他项成功。测试内容不得包含敏感资料。
10. 如果遇到安全验证、访问限制、地区不支持或身份验证要求，停止在该步骤，解释官方提示并让我自行按官方流程处理；不得提供绕过方法。

现在先进行只读环境盘点。请先说明你能检查哪些信息、哪些信息不会读取，然后给我第一条只读检查命令；等我贴回结果后再继续。不要一次性输出一串需要连续执行的命令。

实测声明：只有浏览器登录、Pro 状态（若本次目标包含订阅）、网页端请求、CLI 授权和 CLI 请求都按计划验证后，才可称为本设备本次实测通过。不要把别的设备或账号的结果写成我的实测结果。
```

## 安全边界

- 仅在 Claude 官方支持的地区和官方规则允许的方式下使用。
- 不绕过地区、身份、CAPTCHA、付款或风控要求。
- 不在公开仓库、聊天记录或普通日志中存放令牌、密码、验证码和支付信息。
- “浏览器可访问”“CLI 已登录”“订阅已开通”“请求成功”是不同状态，必须分别验证。
